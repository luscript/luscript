## A little about me

I'm Lu, a software engineer based in Santa Fe, Argentina, studying Computer Engineering at Universidad Nacional del Litoral.

My work spans Java and Spring backend services, SQL data models, AWS integrations, and React and TypeScript frontends. I've worked on reactive services, microfrontends, and automated tests for large-scale products in Latin America. I like being able to follow a feature all the way through: how the data is stored, what the API does with it, and how it reaches the user.

Lately, I've been working in an agentic development environment: using agent orchestration and MCPs, and proposing improvements to the environment itself as I use it. That has made the development workflow part of what I work on, alongside the software.

I'm also integrating Meta's WhatsApp API into a system of the company I work on. A fair amount of that work involves digging through Meta's documentation and figuring out how the pieces fit together.
